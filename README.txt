בניית APK בלי Android Studio:
1. צור מאגר חדש ב-GitHub והעלה אליו את כל תוכן התיקייה (כולל .github).
2. לשונית Actions -> Build APK -> Run workflow.
3. בסיום הורד את KosherDialer-apk מה-Artifacts והתקן בטלפון.

בניה עם Android Studio: File -> Open על התיקייה, ואז Build -> Build APK.

שימוש: זווג את הטלפון הכשר בהגדרות הבלוטות' של האנדרואיד, פתח את האפליקציה, בחר את המכשיר ולחץ 'רענן'.
